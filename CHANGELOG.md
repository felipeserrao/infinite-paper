# Changelog

User-facing changes, newest first. Every change that reaches `main` adds a line under **Unreleased** (what changed and why, in a user's words). The session that publishes a release renames **Unreleased** to the version and uses it as the release notes. Older releases: see [GitHub releases](https://github.com/felipeserrao/infinite-paper/releases).

## Unreleased (next: 1.2.0)

- **See what the lasso will pick.** While you draw a lasso or a box, the ink it would select turns blue, and stays blue once selected (as in tldraw). Very large selections (over 4,000 strokes) show only the dashed box, so panning stays smooth.
- **Eraser shows where it is.** A circle at the pen tip shows how far the eraser reaches, with a short grey trail behind it; erased ink fades and disappears when you lift the pen. The circle also follows a hovering mouse or Apple Pencil.
- **Alignment guides when moving (optional, Settings → Selection).** While you drag a selection, dashed lines run across the page from its edges: horizontal ones when you move it up or down, vertical ones when you move it sideways, to line it up with your other writing. The lines follow the direction you're moving and stay put while you pause to line up. Also a command: "Turn alignment guides when moving on/off".
- **Other styluses.** The eraser end of a pen (Surface Pen, Wacom), or holding its side button (S Pen, Surface), now erases for that stroke and then goes back to the pen.
- **Writing with a finger or a rubber-tip stylus.** These count as a finger, which moves the page. The first time a finger pans on a device where no pen has ever been used, a short hint offers **Let touch draw**. The hand button's choice (touch draws or not) is now remembered on each device instead of resetting every time you open a drawing.
- Repository: the README shows two short demos: writing on a page with 500,000 strokes, and moving, copying and linking handwriting.
- Repository: the README and the plugin's description now explain what it's for: smooth handwriting like tldraw, a whole notebook on one page (tested on iPad with 500,000 strokes), links and moving handwriting between pages, and why a drawing is a regular note.

## 1.1.0 (2026-11-10)

- **Rename a drawing from its title.** Clicking (or tapping) the drawing's name in the header now lets you rename the file, as it does for notes.
- **Menus close when you tap the page.** With a menu open (for example the header's ⋯ menu), a tap or click on the drawing now closes it, instead of the menu staying open until you tap its button again. That tap draws nothing.
- **A resting palm no longer scrolls the page.** One finger now has to really move (about 10 px) before the page pans, and a touch that lands right as the pen lifts (your wrist, between words) is ignored for as long as it stays down.
- **Pen mode (optional, Settings → Touch).** Once the pen touches the page, one finger stops moving it; pan and zoom with two fingers. A **Pen mode ×** chip at the top of the drawing turns it off until you next use the pen (like tldraw's "Exit pen mode").
- **Two-finger scrolling no longer zooms by accident.** A two-finger gesture now first decides whether it's a pan or a zoom (the same rule tldraw uses): moving your fingers together pans with the zoom held still, even if they drift apart a little; spreading or pinching them zooms. A clear pinch during a pan still switches to zooming, without a jump.
- **Make selected ink smaller or bigger.** The selection bar has two new buttons, Make smaller and Make bigger: each tap shrinks or grows the selection a step (0.8× / 1.25×), as if it had been written at another zoom: the pen width scales with it and the top-left corner stays put. Tap again to keep going; each tap is one Undo. On a link box they scale the box and the ink inside it (its corner handle still resizes just the box). There is no corner handle on selected ink, so dragging anywhere in a selection always moves it.
- **Much smaller drawing files.** Strokes are now saved compressed, in blocks of 2,000: about half the size or less (a 167 KB note became 66 KB, a 41.6 MB test notebook 25.9 MB). Nothing about the ink changes: every point is kept exactly. Saving stays quick on big notebooks because only the blocks you changed are compressed again. Older notes still open and switch to the new format the next time they are saved. Notes saved this way need this version or later to open.
- **Compact ink (optional, Settings → File size).** When on, each new stroke is saved as the smooth line you see instead of every point the pen reported: drawings take about 55–60% less space (a 66 KB note became 29 KB; a 500,000-stroke test notebook 25.9 MB → 10.7 MB). The ink stays within about 1 px of what you drew; edges can shift slightly when zoomed in. The command **Compact all ink in this drawing** converts strokes already drawn (Undo brings them back during the session). It's one-way: strokes saved compact stay compact if you turn the setting off; use Obsidian's version history or File recovery to go back.
- **A note that can't be read is never overwritten.** If a drawing fails to load (damaged, or saved by a newer version of the plugin), Infinite Paper shows the error and leaves the file untouched, instead of showing an empty page whose next save would erase it.
- **Unlink a box without losing the ink.** Selecting a link box now shows Open · Change · **Unlink** · Delete. Unlink removes only the box (and its link line in the note's header); the handwriting inside stays selected, so you can link it again, move or copy it. Undo brings the box back. Delete still removes the box and the ink inside it.
- Repository: issue forms, a discussions link and a Feedback section in the README; the release workflow attests build provenance.
